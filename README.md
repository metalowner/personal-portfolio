# Personal Consulting Portfolio & Services Landing 🚀

**Personal Portfolio** — это адаптивный продающий лендинг (Landing Page), разработанный с нуля для позиционирования независимого технического консультанта, архитектора процессов и управляющего цифровыми продуктами (Technical PM / Product Owner / Delivery Manager).

Сайт спроектирован по правилам продуктового маркетинга: фокус на воронку продаж, закрытие болей клиентов в формате совместной разработки (Co-creation), демонстрация услуг на простом бизнес-языке и наглядная витрина кейсов.

---

## 🛠 Технологический стек

* **Framework:** Vue 3 (Composition API), TypeScript, Vite.
* **UI/Styles:** Tailwind CSS (v4) — чистая, современная минималистичная светлая тема.
* **Icons:** Lucide Icons (адаптивные векторные маркеры и визуальные якоря).
* **Architecture:** Component-Driven Architecture (изолированные интерфейсные слои).

---

## 🏗️ Модульная архитектура фронтенда

Проект разделен на независимые, слабосвязанные компоненты для обеспечения высокой производительности и легкости поддержки:
1. `HeroSection.vue` — Главное УТП (уникальное торговое предложение), ценность совместной работы и прямая точка захвата (Call to Action).
2. `ServicesList.vue` — Каталог бизнес-услуг (маркетинг под ключ, разработка сайтов/приложений, UI/UX аудиты интерфейсов, бизнес-планирование франшиз), сформулированный на языке выгод для заказчика.
3. `FrameworkApproach.vue` — Слой отработки возражений и страхов клиентов (простой язык без сложного ИТ-жаргона, регулярные синки, контроль конверсии).
4. `CaseStudies.vue` — Интерактивная витрина, связывающая коммерческий опыт (масштабирование франшизы) и технические репозитории автоматизации.

---

## 💻 Инструкция по запуску

1. Установите зависимости проекта:
   ```bash
   npm install
   ```
2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
3. Откройте приложение по адресу, указанному в терминале (обычно `http://localhost:5173`).
